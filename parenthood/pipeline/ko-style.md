# Korean style guide (한국어판 작성·검토 기준)

The Korean reader reads only the Korean edition. It must say exactly what the English says, in the formal polite
register, and read as if a skilled Korean science journalist had written it for an educated reader — never like a
translation. The validator enforces the mechanical parts (sentence endings, numbers, citations, a few known
mistranslations); everything else here is judgment.

## 1. Register: 합니다체 everywhere
- Every sentence of running text (takeaway, section bodies, bullets, forUs, figure captions, glossary notes, quiz
  text, the emailed question) ends in 합니다체: …습니다 / …입니다 / …ㅂ니다, questions …습니까 / …주시겠습니까,
  requests …해 주십시오 / …하시기 바랍니다.
- Never 해요체 (…해요, …있어요, …하세요, …할까요?, …죠) and never 해라체 (…한다, …이다, …했다).
- Suggestions: …하는 것이 좋습니다 / …해 볼 만합니다 / …상의해 보십시오. Not …하세요.
- Titles, headings, labels and glossary terms may be noun phrases (e.g. "가임력 연구 결과").
- Honorifics for the couple only: 두 분, 유이 님, 폴 님, 드시는, 하실 수 있습니다. Researchers, doctors and
  organisations get plain verbs (연구진은 … 추정했습니다, 지침은 … 권고합니다), not …하셨습니다.

## 2. Fidelity: the same content, not a looser version
- Same claims, numbers, units, ranges and citation markers in every section. Don't turn a percentage into a
  fraction or round a number.
- Keep every hedge: about → 약, up to → 최대, may/can → …ㄹ 수 있습니다, linked to/associated with →
  …와 연관된 / …한 것으로 나타난. Never upgrade association into cause (…때문에, …효과가 있습니다).
- Keep who did what: if researchers estimated something, the Korean subject is the researchers, not the women.
- Keep the logic between clauses. "A, and B" must not become "A이므로 B" or "A라서 B". A caveat followed by a
  separate fact is two sentences: "다만 두 연구 모두 관찰 연구입니다. … 무작위 대조 시험은 아직 드뭅니다."
- Allowed additions: an English term in parentheses, a short gloss of a technical word
  ("부당경량아(임신 주수에 비해 작은 아기)"), or common examples ("연어·고등어 같은 기름진 생선"). Never a new fact
  or number.

## 3. Natural Korean, not translationese
Compose each paragraph from the facts, in Korean order: context first, the finding, then its meaning. Split long
English sentences; merge choppy ones. Read it aloud in your head: if a Korean editor would pause, rewrite it.

Avoid:
- English idioms rendered literally: "긴 꼬리" (long tail), "게임 체인저", "그림이 자라납니다" (the picture grows).
- "~로 끝나는 6일" for "the six days ending on ovulation" → "배란일까지의 6일".
- Pronouns 그/그녀/그들/그것 → repeat the noun or drop it.
- "~에 의해" passives and "~되어지다" → active sentences.
- Sentence-initial "그리고"; lists written "A, B, 그리고 C" → "A, B, C" or "A와 B, C".
- "이 ‘X’" when X has not been named yet → "이른바 ‘X’".
- Colloquial connectives in formal prose: "~니까", "~으니", "~라서" → "~므로", "~기 때문에", "~어서".
- The same word twice in one sentence (지금 … 지금, 이런 … 이런), and two "에서" in one clause.
- "결과(outcome)" in lay text → name the outcome, or "건강 효과", "지표".
- Transliterations where Korean has a word: 프리내털 → 산전 영양제, 슬립 → 수면.

## 5. Numbers, units and spacing
- Digits as in English; ranges with "~" (12~24시간, 600~5,000IU); units attached (30ng/mL, 1,000IU, 38%).
- Lab values: "수치 30대 초반", never "30점대".
- Metric units; add the US unit in parentheses only when a US threshold matters.
- Large numbers may use 만/억 (60만 개 이상) but must stay the same number.
- Cycle days "11일째"; weeks of pregnancy "임신 12주"; dates "12월 1일".
- Particles follow how a term is read aloud: LH가, AMH는, IVF를, 25(OH)D는, 30ng/mL는.
- Standard 띄어쓰기: 할 수 있습니다, 이틀 안에, 그다음 날, 한 번, 하루 1,000IU.

## 6. Mistakes already made (don't repeat them)
| Wrote | Better | Why |
|---|---|---|
| 저체중아 (for small-for-age babies) | 부당경량아(임신 주수에 비해 작은 아기) | different medical term |
| 비타민 D 30점대 | 비타민 D 수치 30대 | 점대 means test-score points |
| 배란일로 끝나는 6일 | 배란일까지의 6일 | calque of "ending on" |
| 긴 꼬리는 생각보다 덜 중요합니다 | 오래된 정자의 기여는 생각보다 작아 | English idiom |
| 두 근거 모두 관찰 연구라서 … 무작위 시험은 드뭅니다 | 다만 두 근거 모두 관찰 연구입니다. … 아직 드뭅니다 | invented a causal link |
| 이 ‘비타민 D 겨울’이 | 이른바 ‘비타민 D 겨울’이 | first mention |
| 등푸른생선 (for fatty fish) | 연어·고등어 같은 기름진 생선 | excludes salmon |
| 상한선 | 상한 섭취량 | standard nutrition term |
| …달라질 수 있으며, ODS가 … 운영하는 이유이기도 합니다 | …다를 수 있습니다. ODS가 … 운영하는 것도 이 때문입니다 | subject mismatch |
| 담당 의사와 상의해 볼 계획은 …하는 것입니다 | …하는 계획을 담당 의사와 상의해 볼 만합니다 | English sentence frame |
| 다시 입력해 주세요 / 누가 읽나요? / 시작하세요 | 다시 입력해 주십시오 / 이 기기에서 읽으실 분 / 시작하는 것이 좋습니다 | 해요체 |
| 3분 읽기 | 3분 분량 | calque of "3 min read" |
